プライバシーポリシー

「つなぐ手帳」（以下、本ツール）は、作成者本人が個人で使うためのツールです。

取得する情報

本人の Google アカウントの許可にもとづき、Google Health から次のデータを読み取ります（読み取りのみで、書き込みや削除はしません）。

  • 運動の記録（サイクリングの日時と時間）
  • 睡眠の記録（日ごとの睡眠時間）
  • 安静時心拍数

利用目的と保存先

週ごとの集計値（サイクリングの合計時間、7時間以上眠れた日数、安静時心拍の平均）を計算し、本人の Google スプレッドシートに書き込むためだけに使います。元のデータを別の場所に保存することはありません。

第三者への提供

取得した情報を第三者に提供・販売・共有することはありません。広告にも使いません。

Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用と移転は、限定使用の要件を含む Google API Services User Data Policy に従います。

許可の取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも許可を取り消せます。
